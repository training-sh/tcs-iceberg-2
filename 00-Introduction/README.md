# OpenShift introduction

Run `02-Installation.ipynb` from the VM terminal. Its command cells are tagged
`vm-terminal` because cluster administration requires the `crc`, `oc`, and
`kubectl` programs installed on the VM.


Read [`03-Architecture.ipynb`](03-Architecture.ipynb) for the illustrated slide deck covering the stack, pods, containers, storage, databases and CRC system services. Diagram sources and PNG/SVG assets are in `assets/`; rebuild them with `python assets/build_architecture.py` (Pillow required).
